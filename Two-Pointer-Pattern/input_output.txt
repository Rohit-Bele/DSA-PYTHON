# 3. Two Integers — Same Line

### Input

```text
5 10
```

### Code

```python
n, target = map(int, input().split())
```

Result:

```python
n = 5
target = 10
```

### Important

This does **not** create a list.

It creates two variables.

# 5. Array — All Elements on One Line ⭐

This is very important for TCS.

### Input

```text
10 20 30 40 50
```

### Code

```python
arr = list(map(int, input().split()))
```

Result:

```python
arr = [10, 20, 30, 40, 50]
```

### Breakdown

```python
input()
```

gets:

```text
"10 20 30 40 50"
```

```python
.split()
```

gives:

```python
["10", "20", "30", "40", "50"]
```

```python
map(int, ...)
```

converts them to integers.

```python
list(...)
```

creates:

```python
[10, 20, 30, 40, 50]
```

---

# 6. `n` + Array

Very common.

### Input

```text
5
10 20 30 40 50
```

### Code

```python
n = int(input())
arr = list(map(int, input().split()))
```

Result:

```python
n = 5
arr = [10, 20, 30, 40, 50]
```

You **don't need a loop** to take the array if all elements are on one line.

---

# 7. `n` + Target + Array

### Input

```text

10 20 30 40 50
```

### Code

```python
n, target = map(int, input().split())
arr = list(map(int, input().split()))
```

Result:

```python
n = 5

arr = [10, 20, 30, 40, 50]
```

# 8. Array Elements on Separate Lines

Sometimes the format can be:

```text
5
10
20
30
40
50
```

Then you need a loop:

```python
n = int(input())

arr = []

for _ in range(n):
    arr.append(int(input()))
```

Result:

```python
arr = [10, 20, 30, 40, 50]
```

### ⚠️ Don't automatically use this.

Use it **only when the input format actually gives one element per line.**

# 16. Matrix Input ⭐

Suppose:

```text
3 3
1 2 3
4 5 6
7 8 9
```

Here:

```text
3 3 → rows, columns
```

Code:

```python
rows, cols = map(int, input().split())

matrix = []

for _ in range(rows):
    row = list(map(int, input().split()))
    matrix.append(row)
```

Result:

```python
[
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

For a matrix, a loop is normally necessary because **each row is a separate input line**.

# 26. Don't Add Extra Text ❌

Don't write:

```python
print("The answer is", ans)
```

if expected output is only:

```text
25
```

Instead:

```python

```

The judge compares your output with the expected output.

### Multiple integers

```python
a, b = map(int, input().split())
```

### Integer array

```python
arr = list(map(int, input().split()))
```

### String

```python
s = input()
```

### String array

```python
words = input().split()
```

### Matrix

```python
matrix = []

for _ in range(rows):
    matrix.append(list(map(int, input().split())))
```

### Multiple test cases

```python
t = int(input())

for _ in range(t):
    # input + solution
```

### Print array

```python
print(*arr)
```

# 🧠 Your TCS Mental Process

When you see a question, **don't immediately start coding the logic**.

First look at:

```text
INPUT FORMAT
       ↓
What is given first?
       ↓
Integer?
Array?
String?
Multiple values?
Multiple test cases?
       ↓
Same line or separate lines?
       ↓
Choose input code
       ↓
Write logic
       ↓
Print exactly as OUTPUT FORMAT says
```

### Example

If the question says:

```text
Input:
5
10 20 30 40 50

Output:
150
```

Immediately think:

```python
n = int(input())
arr = list(map(int, input().split()))

# logic

print(answer)
```

That's the **TCS hands-on style** you should practice.

And one correction to what we discussed earlier: **there isn't one universal TCS interface/input format for every coding question**. The exact input format is determined by the individual question, so your safest habit is always to follow its stated Input Format rather than assuming it will be like LeetCode.
